# FiveM

### GTA V multiplayer modification framework

FiveM is the leading modification framework for Grand Theft Auto V, enabling custom multiplayer servers with unique game modes, roleplay servers, racing leagues, and entirely new gameplay experiences built by the community.

<br>

---

## Features

| | |
|:---|:---|
| **Custom Servers** | Join thousands of community servers with unique rules and game modes |
| **Roleplay Ready** | Optimized for the massive GTA RP server ecosystem |
| **Resource System** | Server-side Lua and JavaScript resources for unlimited customization |
| **Anti-Cheat** | Built-in protection keeps servers fair for legitimate players |
